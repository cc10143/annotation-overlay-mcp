Annotation Overlay MCP Demo

Ctrl+Shift+A to start — 6 tools for visual feedback

Getting Started

This demo page tests all 6 annotation tools. The overlay auto-injects when loaded via the Chrome extension, or activate manually with Ctrl+Shift+A.

new

Arrow & Box Tools

Click and drag to draw arrows (pointing at elements) or boxes (enclosing regions). Each annotation records the DOM element under the target point.

Try pointing at the buttons below:

Click-to-Select (+)

Select the + tool, hover to see blue outline highlights, then click any element to pin a numbered badge. The element's CSS selector and text are captured automatically.

  • Try clicking the success badge
  • Or the danger badge
  • Or this entire card itself

Text Selection ([ ])

Select the [ ] tool, then select any text on this page with your mouse. A comment input will appear at the selection position. The annotated text and its containing element are both recorded.

Try selecting this sentence to annotate it.

Or select part of any paragraph — the tool captures the exact text you highlight along with the element selector.

Freehand & Text Label

The freehand tool (✎) lets you draw freely. The text tool (T) places a comment label at any click point.

Use these for annotations that don't map to a single element — like "this whole area needs redesign" or "add more spacing here."

Submit Workflow

Each annotation stays on the page (as canvas drawings + numbered badges). When you're done marking issues, click Submit to send everything as structured JSON to the MCP server. Claude Code reads them via the read_annotations tool.

After agent fixes and page refreshes, the overlay auto-reinjects — ready for the next round.
