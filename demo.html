Getting Started

This is a demo page for testing the annotation overlay. Each card represents a UI component you might want to annotate.

Keyboard Shortcuts

Ctrl+Shift+A toggles the overlay. Ctrl+Z undoes the last annotation. Press Escape to cancel or close.

Drawing Tools

Four tools available: arrow (point at things), box (enclose regions), text (place labels), freehand (draw freely).

DOM-Aware

Every annotation automatically links to the DOM element underneath. The output JSON includes CSS selectors — grep your source code directly.
